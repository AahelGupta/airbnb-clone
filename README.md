## 🏡 Overview

**Airbnb Clone** is a full-featured vacation rental platform constructed with **React.js**, **Context API**, and **Tailwind CSS**. It replicates the core user workflows of Airbnb including category browsing, search filters, interactive property booking, user authentication, and trip management.

---

## ✨ Key Features

- 🔍 **Dynamic Search & Category Filtering**: Filter listings by location, guest capacity, price range, and property categories.
- 📅 **Interactive Booking Widget**: Date range picker, guest count calculation, and real-time total price breakdown.
- 🧳 **Trip & Booking Management**: User trips modal displaying active reservations.
- 👤 **Authentication Simulation**: AuthModal supporting login & signup workflows with context state.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/AahelGupta/airbnb-clone.git

# Install dependencies
npm install

# Start development server
npm run dev
```
